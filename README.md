# ExplainableCropAI

Interpretable Deep Learning for Agricultural Disease Detection and Decision Support

## Project Structure

- `/data` - Dataset storage and preprocessing scripts
- `/src` - Source code for the explainable AI models and components
- `/models` - Saved model checkpoints and weights
- `/notebooks` - Jupyter notebooks for exploration and visualization
- `/docs` - Documentation and supplementary materials
- `/results` - Experimental results, metrics, and evaluation data
- `/presentations` - Presentation materials and slides
- `/paper` - Research paper drafts and final version

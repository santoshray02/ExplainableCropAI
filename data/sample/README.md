# Sample data (illustrative only)

The CSV files in this folder are small hand-written examples used by the figure and
interface mock-up scripts in `src/visualization/` and by the demo notebook. They show the
*format* of the pipeline's outputs (per-pass MC Dropout probabilities, generated
explanations, treatment recommendations) and are **not experimental results**. Their class
list predates the switch to the official Paddy Doctor label set and does not match it.

Every number reported in the paper comes from the files in `experiments/outputs/`, which
are produced by the scripts in `experiments/`.

\begin{abstract}
While deep learning has significantly improved automated crop disease detection, most current systems function as inscrutable "black boxes," limiting farmer trust and adoption. This paper presents ExplainableCropAI, a novel framework that integrates accurate paddy disease detection with multi-level explanations and context-aware recommendations. Our approach combines visual evidence highlighting (Grad-CAM), uncertainty quantification (Monte Carlo Dropout), and domain-specific natural language explanations to provide transparent and actionable insights. We demonstrate that this explainable system achieves 90\% disease classification accuracy while generating interpretable visual explanations that highlight disease-relevant regions. Through a preliminary user evaluation with agricultural domain participants, we show that explanations improve user trust and decision-making accuracy compared to unexplained predictions, with particular benefits for users with varying levels of domain expertise. The system's recommendation engine generates contextual treatment and prevention suggestions designed to support agricultural decision-making. These findings demonstrate that explainability can transform deep learning from a black-box prediction tool into an assistive technology that augments farmer decision-making—a critical advancement for responsible AI deployment in agriculture.
\end{abstract}
